# PRD

## Product Positioning

本项目是 AI 数字人口播视频生成平台。用户通过文案、音频和数字人视频生成口型视频，再在第三步完成字幕、标题、封面和最终成片包装。

当前阶段是 V1.0 后优化与稳定性迭代：线上主流程已经通过，新增需求默认以不破坏现有链路为前提。

## Target Users

- 内容创作者：批量生产口播类短视频。
- 运营人员：用固定数字人和模板快速生成内容。
- 管理员：管理账号权限、用户资源、素材和系统状态。

## Core Workflow

1. 用户登录后进入 `/studio`。
2. 准备口播文案，可从链接提取、手动编辑或分段调整。
3. 点击下一步时创建创作任务，用户可编辑任务名，系统生成唯一 `projectId`。
4. 上传或生成配音，系统保存 `audioAssetId` 并绑定到当前 `projectId`。
5. 基于音频生成秒级字幕时间轴，系统保存 `subtitleTrackId`。
6. 选择当前账号可用的数字人视频，创建口型生成任务。
7. 口型任务成功后保存 `digitalHumanVideoAssetId`，当前任务可继续进入第三步；刷新或离开页面后按 `projectId` 恢复，不自动匹配其他任务的历史口型视频。
8. 第三步选择或编辑字幕模板、标题模板、位置和样式。
9. 最终成片只做包装渲染：字幕烧录、标题叠加、音频视频对齐、输出保存。

## Core Capabilities

### Account And Permission

- 普通新注册用户默认无核心功能权限。
- 管理员开通权限后，用户才能使用创作、素材和生成能力。
- 修改密码支持登录后修改；忘记密码通过手机号和身份证校验恢复。

### Resource Library

- 数字人视频、音色、字幕模板、生成音频和生成视频均按用户隔离。
- 推荐素材可作为公版展示；用户私有素材只能本人读取和使用。
- 资源流接口必须鉴权，不能因为知道文件名就直接访问。

### Audio And Subtitle Timeline

- 文案确认后必须先存在创作任务，后续音频和字幕都绑定 `projectId`。
- 音频可以通过 TTS 生成或上传完成登记。
- 生成音频后必须尽快显示试听状态和失败原因。
- 字幕时间轴使用 ASR 结果生成，支持 `startTime/endTime` 秒级定位。
- 用户编辑后的字幕文本和时间要保存到 `subtitle_tracks`。

### Digital Human Video

- 用户只能选择自己保存的数字人视频。
- 口型生成是异步任务，不阻塞主接口。
- 不再根据音频、数字人视频、渲染模式或文案自动匹配历史口型资产。
- 同一用户创建多个相似任务时，也必须以 `projectId` 区分，不能把 A 任务口型结果自动塞入 B 任务。
- 文件缺失、任务失败或输入变更时不能误用旧结果。

### Creation Task Retention

- 任务名是用户可编辑字段，用于列表展示和搜索，允许重复。
- `projectId` 是文案、音频、字幕、数字人视频、模板和最终成片的唯一关联点。
- 用户可以从任务列表继续编辑已有任务，系统按 `projectId + 当前账号` 恢复内容。
- 归档任务不删除底层资产，但不再出现在默认任务列表。

### Template Editing

- 公版字幕模板只读；用户必须复制后才能编辑。
- 复制后的模板归属当前用户，可修改封面、字幕、标题、颜色、阴影、背景、位置和画幅。
- 模板保存后的样式数据必须参与最终成片渲染。

### Title Assets

- 用户选中文案后可以创建 `title_effect` mark。
- 标题素材异步生成透明背景资产，成功后在最终成片阶段叠加。
- 标题素材失败不能影响文案保存、字幕高亮和其他标题素材。

## Non Goals

- 不在 V1.0 后优化期推翻三段式主链路。
- 不自动执行生产发布、生产回滚或生产数据库破坏性变更。
- 不在未确认的情况下触发真实付费 AI provider 调用。
- 不把历史调试接口作为新功能入口。

## Acceptance

- 刷新页面或切换页面后，已成功生成的音频和字幕时间轴能恢复；口型视频不自动匹配历史结果。
- 每个用户只能看到自己的私有资源和生成记录。
- 第三步最终成片读取已保存的字幕时间轴和模板样式。
- 所有长任务都有任务 ID、状态查询、失败原因和可重试路径。
