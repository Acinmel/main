# UI Guide

## LipSync Preview Format Rule

- `/studio` 第二步口型预览必须按源视频真实画幅展示，不得因为字幕模板、第三步包装比例或默认竖版策略把预览容器误导为 `1080x1920`。
- 第二步生成口型视频时，前端固定提交 `renderMode=preserveSourceAspect`；只有第三步用户明确选择最终输出画幅时，才允许包装成片改变画布。
- 如果后端返回“口型输出未保持源视频格式”一类失败原因，前端应在口型生成区域展示错误和重试入口，不得把异常输出视频展示为成功预览。

## Product Surface

当前核心页面：

- `/studio`：创作台主流程。
- `/projects`：创作任务列表，按当前账号分页展示任务并进入 `/studio?projectId=...` 恢复。
- `/resources`：素材库，包含数字人、音色、字幕模板。
- `/digital-human`：数字人相关素材入口。
- `/admin/dashboard`：管理员后台。
- `/login`、注册、改密和找回密码页面。

旧任务页或历史实验页不得作为新功能主入口。

## Studio Flow

### Step 1: 文案准备

- 用户可以提取、粘贴或手动编辑口播文案。
- 点击下一步前必须创建创作任务，弹出任务名编辑面板，默认任务名可来自来源标题、文案摘要或日期。
- 创建成功后地址栏或页面状态必须带有真实 `projectId`，避免继续写入 `studio-current`。
- 文案分段编辑应可滚动，不得被侧栏或底部时间轴遮挡。
- 选中文案后可显示浮动工具条：高亮、标题。
- 对文案的便捷拆行、插入行、行号更新不能改变最终提交数据结构。

### Step 2: 音频与数字人口型

- 配音设置下拉框只显示当前用户可用音色和推荐音色。
- 已保存视频下拉框只显示当前用户可用数字人视频。
- 选择视频后应优先显示轻量预览，避免用户长时间等待空白区域。
- 生成音频、生成口型视频必须有明确进度、失败原因和可重试入口。
- 生成成功后刷新页面或离开返回，按 `projectId` 恢复该任务的音频试听和字幕时间轴；口型视频不再自动匹配其他任务的历史结果。

### Step 3: 智能剪辑与包装

- 字幕模板选择只保留一个主入口：“更换模板”。
- 中间“文字字幕”区域只负责编辑文案和字幕时间，不重复提供模板选择。
- 切换模板时不能把文案编辑框改成亮色不可读文本；编辑框应保持白底深色字。
- 字幕、标题、封面样式通过模板编辑器保存，最终成片读取保存后的样式数据。

## Template Library

### Public Template

- 公版模板可预览、可复制、不可直接修改。
- Hover 后显示复制和预览。
- 公版预览页不显示保存修改按钮。

### User Copy

- 用户复制公版后生成自己的模板副本。
- 用户副本可编辑并保存。
- 可编辑项包括：
  - 封面第一行和第二行文字。
  - 显示时长，支持全程显示和自定义秒数。
  - 字体大小、花字、文本颜色、对齐方式、阴影、描边。
  - 背景颜色，支持透明。
  - 垂直位置、水平位置。
  - 字幕、标题和封面分别保存样式。
  - 画幅比例：`9:16`、`16:9`、`1:1`、`4:5`。

## Creation Task List

- 任务列表只显示当前账号的创作任务。
- 任务列表必须分页读取，切换筛选或页码时取消上一轮未完成请求。
- 打开详情、改名、归档和恢复时必须显示对应行加载态，并禁止重复点击。
- 列表项展示任务名、更新时间、阶段状态、来源标题和最近生成结果状态。
- 任务名可重复；搜索命中后进入详情仍必须使用 `projectId`。
- 支持继续编辑、改名、归档；归档不是删除，不应误删音频、字幕或视频资产。
- 从任务列表进入创作台时，应显示恢复加载态；恢复失败要展示可重试错误，不要静默清空用户内容。
- 创作台恢复项目期间不应初始化或自动播放大视频预览；视频只在恢复完成或用户主动打开预览后挂载。

## Visual Editor

- 视频预览区域按真实画幅展示安全区、字幕框和标题框。
- 字幕框和标题框可拖拽定位。
- 可输入 `x/y` 百分比，便于精确控制。
- 拖拽结果必须保存到模板样式或项目样式中。
- 预览样式和最终渲染样式必须使用同一份参数。

## Progress And Feedback

- 音频生成进度条不得被试听模块遮挡。
- 视频生成进度应表达真实阶段：
  - 音频准备。
  - 字幕时间轴。
  - 口型生成。
  - 字幕和标题包装。
  - 音视频对齐。
  - 输出发布。
- 每个长任务区域必须提供：
  - `pending` 等待态。
  - `processing` 进度态。
  - `completed` 可预览态。
  - `failed` 失败原因和重试按钮。
- `/studio` 同一口型任务、包装任务或标题素材任务只能保留一个活跃轮询；离开页面、切换任务、完成、失败或超时时必须停止轮询。
- 保存文案、字幕时间轴和阶段状态时，相同内容不应重复提交；失败提示必须保留在触发区域附近或 toast 中。

## Layout Rules

- 创作台优先使用工作台布局，不做营销式大 hero。
- 操作区、预览区和参数区边界清晰。
- 不把卡片再嵌套进卡片。
- 文本不得溢出按钮、标签、表格和卡片。
- 移动端保留核心操作入口，侧栏内容改为抽屉或纵向堆叠。
- 图标按钮使用清晰 tooltip，重要命令同时保留文字。

## Media Preview Rules

- 图片和视频预览不要直接暴露未鉴权私有资源 URL。
- 预览优先走后端鉴权流接口或短时签名 URL。
- 视频预览使用固定尺寸容器，避免加载完成后页面跳动。
- 选择视频后可以先显示封面或低清预览，再切换到完整视频。

## Accessibility And Contrast

- 白色背景上的正文使用深色文本。
- 亮色字幕模板只影响视频预览和最终渲染，不影响表单输入可读性。
- 按钮、输入框、下拉框需要有可见 focus 状态。
- 错误提示应靠近触发区域，不能只依赖 toast。
